## Usage

### 回答する

1. ログインして workspace で待つ。

2. 問題がページ上部に送られてくる。

3. 自分の VScode/Python でその問題を解く。

4. VScode で動作を確認後、そのコードをコピー、

5. j.py の "your answer please." のテキストエリアにペースト、送信。


### 自分の回答を確認する

workspace の answers の下に、回答した日時のリンクがあるので、それをクリック。
